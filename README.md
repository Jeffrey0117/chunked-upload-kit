# chunked-upload-kit

**Chunked/resumable file upload — zero-dep server store + fastify/express adapters + browser/Node client. Gets large files past proxies that cap request bodies (e.g. Cloudflare 100MB).** 零依賴、框架無關。

## 安裝

```bash
npm i github:Jeffrey0117/chunked-upload-kit   # 或直接複製 index.js
```

## 用法

```js
const create = require('chunked-upload-kit');
const x = create({ /* opts */ });
```
